After turning your phone for the first time, you can see why it was so cheap. Xiaomi WILL install dozens of useless apps by default, even marked as necessary, while including Clash of Clans in that list. You can deselect some of them, but you still have to wait for the phone to install the rest. Now only that, system apps like Music Player, Theme Store, and even File Explorer have ads baked in, not always toggleable. Plus, you have your standard tracking and pointless stuff like their app store and a compass app. You can go uninstall the apps one by one (if it can be removed in the first place), but overall, the best way to do this and remove some apps you didn't even know were there is using Canta.
